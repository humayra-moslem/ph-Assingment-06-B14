# 🏋️ FitLog – Fitness & Workout Planner

FitLog is a fitness and workout planning web application designed to help users explore workouts, create personalized workout plans, save their favorite exercises, and track their fitness progress. Users can browse different workouts, view detailed exercise information, organize their daily routines, and mark exercises as completed, all through a simple and interactive interface.



## 🛠️ Technologies Used

- **Next.js** – React framework for building the application
- **React** – Building interactive user interfaces
- **TypeScript** – Type safety and better code maintainability
- **Tailwind CSS** – Responsive and modern UI styling
- **DaisyUI** – UI components and styling utilities
- **REST API** – Fetching workout data from an external API
- **Vercel** – Application deployment

## ✨ Key Features

### 1. Workout Library
- Browse a collection of available workouts
- View workout information, including duration, calories burned, equipment, and ratings
- Explore different exercises through an organized interface

### 2. Workout Details
- View detailed information about individual workouts
- Access workout details using dynamic routes
- Fetch individual workout data using its unique ID

### 3. My Workout Plan
- Add workouts to your personal workout plan
- View all planned workouts in one place
- Remove workouts from your plan
- Mark completed workouts as **Done**

### 4. Save Favorite Workouts
- Save favorite workouts for later
- Access saved workouts through a separate tab
- Remove workouts from your saved collection

### 5. Workout Progress & Sorting
- View workout statistics, including total exercises, duration, and estimated calories
- Sort workouts by duration, calories burned, and rating
- Track completed exercises to stay consistent with your fitness goals
